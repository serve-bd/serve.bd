Serve is built in the open on [GitHub](https://github.com/serve-bd/serve). Pick the place that fits what you need.

## Ask a question

Use [Discussions](https://github.com/serve-bd/serve/discussions) for questions, ideas, and things you built with Serve. Search there first: someone may have asked already.

## Report a bug

Use the [bug report form](https://github.com/serve-bd/serve/issues/new?template=bug_report.yml). Say what you did, what you expected and what happened, and add the Serve version from **Settings → Updates**. Logs help.

## Request a feature

Use the [feature request form](https://github.com/serve-bd/serve/issues/new?template=feature_request.yml). Describe the problem you want to solve, not only the solution.

## Request a template

Use the [template request form](https://github.com/serve-bd/serve/issues/new?template=template_request.yml). Give the app, its website or repository, and its official Docker image. To add a template yourself, see [Contributing a template](/docs/templates#contributing-a-template).

## Report a security problem

Do not open a public issue, discussion or pull request for it. Report it privately through [GitHub security advisories](https://github.com/serve-bd/serve/security/advisories/new).

- You get an answer within 3 working days.
- Only the latest release gets security fixes, so keep Serve [up to date](/docs/updating).

## Contribute

Read [CONTRIBUTING.md](https://github.com/serve-bd/serve/blob/main/CONTRIBUTING.md) for the development setup, the checks to run, database migrations and templates. Everyone who takes part follows the [code of conduct](https://github.com/serve-bd/serve/blob/main/CODE_OF_CONDUCT.md).

For anything else, write to [contact@serve.bd](mailto:contact@serve.bd).
